Nova organização do menu lateral

Pagamentos RAD passa a ficar dentro de Crédito, e Conciliação e Inconsistências passam a ficar dentro de um grupo novo, Apuração Assistida. O menu cai de nove para sete itens de primeiro nível. Nenhuma tela muda por dentro: muda onde cada uma fica e como se chega nela.

03Como o menu se comporta
  • Grupo aberto: o clique no nome do grupo expande os itens e abre o primeiro — Crédito abre Visão geral; Apuração Assistida abre Conciliação.
  • Item ativo: o item fica destacado e o grupo dele também, para saber onde se está.
  • Um grupo por vez: abrir Apuração Assistida recolhe Crédito, como já acontece com Configurações.
  • Menu recolhido: só os ícones. O clique abre o primeiro item; passar o mouse mostra os itens do grupo.

06O que muda por baixo
  • Os ids dos botões ficam (nav-creditos-btn, nav-pagamentos-btn, nav-conciliacao-btn, nav-inconsist-btn): as feature flags e o backoffice escondem recursos por esses ids.
  • rotas.js passa a achar o item dentro do grupo, não só o botão de primeiro nível.
  • Perfil fornecedor: as regras que escondem grupos passam a valer para os dois grupos novos.
  • Atalhos do Início (Ver créditos, Ver pagamentos, Ver conciliação, Ver inconsistências) abrem o item e o grupo certos.
  • Títulos das telas: Pagamentos vira Pagamentos RAD; Inconsistência vira Inconsistências.
  • Flag: o menu novo fica atrás da flag menu_agrupado; com ela desligada, o menu de hoje continua como está.
07Documentação que acompanha

Na implementação, os caminhos de tela passam a ser os novos nos documentos que os citam:

  • PRDs de Crédito, Pagamentos, Conciliação, Inconsistências e Início (atalhos).
  • Mapa de funcionalidades: os grupos de módulos.
  • Jornadas e caderno de testes: os passos que dizem "abra Pagamentos" ou "abra Conciliação".
  • Relatório de avaliação: o campo Onde ver dos itens.
