01Objetivo e escopo
Objetivo central: capturar Documentos Fiscais eletrônicos emitidos ou recebidos pela Positivo Tecnologia S.A. via ERP ou upload manual, validá-los e integrá-los à base SplitHub para alimentar a Apuração Assistida de IBS/CBS e garantir a apropriação do crédito.
02Fontes de ingestão
FonteProtocoloPrioridade
ERP / sistema de origemAPI REST · Webhook · SFTPP1
Upload manual (XML/ZIP)Interface web · drag-and-dropP2
03Validação e integração
Etapas de validação
  • Layout: validação de schema XSD, encoding UTF-8, assinatura digital
  • Dados: CNPJ emitente/destinatário, CFOP, alíquota CBS, duplicidade por chave
  • Integração: criação do Registro Fiscal (RF) com ID único e timestamp
Interface — Listagem de DFs
  • Colunas: NF, Tipo DF, Emitente, Valor, Emissão, Ingestão, Status
  • KPIs resumidos: total, integrados, erros
  • Botão de importação manual (XML/ZIP)
04Requisitos funcionais
RF-ING-01 · Integração com ERP

Receber DFs do ERP em tempo real via webhook ou em lote via SFTP/API REST. Garantir idempotência por chave de acesso.

RF-ING-02 · Validação de layout

Validar XML contra schema XSD oficial. Falha resulta em status erro_layout.

RF-ING-03 · Importação manual

Upload de XML/ZIP com feedback em tempo real: progresso, erros por arquivo, resumo de integrados vs. rejeitados.
