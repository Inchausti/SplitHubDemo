# SplitHub Roadmap

Visão de longo prazo e plano de desenvolvimento para o SplitHub.

## Q2 2026 (Atual)

### Em Progresso
- [x] Dashboard base
- [x] Gestão de pagamentos
- [x] Gestão de créditos
- [ ] Integração com API real
- [ ] Gráficos interativos com dados reais

### Planejado
- [ ] Relatórios exportáveis (PDF/Excel)
- [ ] Agendamento de pagamentos
- [ ] Alertas via email/SMS
- [ ] Testes e2e

## Q3 2026

### Features
- Automação de fluxo de pagamento
- Dashboard customizável
- Integração com ERP
- API GraphQL
- Mobile app (React Native)
- Análise de tendências avançada

### Infra
- Migração para serverless
- Caching distribuído
- CDN global
- Multi-tenancy completo

## Q4 2026

### Machine Learning
- Previsão de créditos
- Detecção de anomalias
- Otimização de pagamentos
- Análise preditiva de risco

### Compliance
- SOC 2 Type II
- ISO 27001
- PCI DSS
- LGPD compliance

## 2027+

### Vision
- Plataforma completa de gestão tributária
- Integração com mercado financeiro
- Marketplace de serviços
- Comunidade de usuários

## Como Sugerir Features

1. Abra uma issue com a label `feature-request`
2. Descreva o caso de uso
3. Deixe comentários de suporte
4. Discuta na comunidade

- 🐛 Reporte bugs encontrados
- 📝 Sugestione melhorias
